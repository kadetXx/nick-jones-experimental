## NickJones Experimental

Rebuild of [NickJones's portfolio](https://narrowdesign.com/) using html/css/js and the fibonacci sequence.

### Running The Project

No build step — the page is plain html/css/js. Open `index.html`, or serve the
folder if you want a real origin:

```bash
python3 -m http.server
```
